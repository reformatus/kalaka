makes or confirms it. Later decisions may refine or supersede earlier ones;
the later entry says so. "Architecture §N" refers to the
[architecture page](architecture.md). Names of plugins, modules, hooks and
code identifiers are placeholders.

| D-055 | 2026-10-25 | **Use-case runner:** resolve the actor → check input against the schema → coarse permission check → begin transaction → execute (fine permission checks, changes) → audit entry → commit → run the post-commit evaluation (D-057). **Any** database error rolls back the whole use case; code never continues after catching one.
