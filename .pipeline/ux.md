# UX notes for Kaláka

Today `plugins/kalaka/` registers no admin menus, blocks, shortcodes or REST
routes, so there are no user-facing pages yet. This file grows as pages are built.

Who uses it:

- Organisation staff, in wp-admin.
- Registrants, on the front end.

Always check: every visible text is Hungarian and approved, and nothing
unapproved appears in the UI.
