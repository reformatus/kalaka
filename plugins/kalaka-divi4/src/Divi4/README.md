# Divi4

The Divi 4 theme adapter: one extension plugin, `kalaka-divi4` (module `divi4`). It contributes `DiviThemeAdapter` through `Contributions::themeAdapter()`: under Divi 4 (the template `Divi`, also with a child theme, at a version below 5; Divi 5 gets its own adapter later) a form gets Divi's contact-form classes (`et_pb_contact et_pb_contact_form` on the form, `et_pb_contact_field` on each field, `input et_pb_contact_message` on text controls, `et_pb_contact_submit et_pb_button` on the button), `p` wrappers for text-like fields and Divi's form red (`#ff0000`) as the error colour.

`Module::boot()` asks Divi's dynamic assets for the contact form's styles (`et_required_module_assets`, and `et_dynamic_assets_modules_atf` so they come inline as critical CSS, which works without JavaScript) on pages holding a form or the status block, and adds the spacing of `div` fields (a choice, a consent) and, on an iPhone, the native appearance of Kaláka's checkboxes and radio buttons, except the ranking's +/× toggle, which Kaláka draws itself (`Module::IPHONE_CONTROLS`: Divi's `.iphone .et_pb_contact_form input{-webkit-appearance:initial}` leaves them 0×0) on pages whose content holds the `kalaka/form` block or the `[kalaka_form]` shortcode.

On a page whose content holds the `kalaka/status` block or the `[kalaka_status]` shortcode, the same stylesheet gives the registrant's money table Divi's row line on the row headers (`Module::MONEY_TABLE`): Divi draws a `#eee` line on the top of a `td` and none on a `th`. The table's structure and its emphasis (`em`, `strong`) are core's.

The icon of Divi's button (an arrow glyph shown on hover) gets an empty text alternative on Kaláka's own buttons (`Module::BUTTON_ICON`), so a screen reader does not read it; the look is Divi's. Those buttons also get the ranking's dark focus ring back, which Divi's `:focus { outline: 0 }` removes, and the card payment button drops the left margin of a contact form's submit (`Module::BUTTONS`).
